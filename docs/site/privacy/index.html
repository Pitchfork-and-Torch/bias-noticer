Privacy Policy

Effective: 2026-09-01 · Product: Bias Noticer browser extension v2.1.0

Summary

Bias Noticer is privacy-first. Your xAI API key and settings stay in your browser’s local storage. We do not run ads or sell your data. When you choose to run cloud analysis, article text you select is sent to xAI under your account. Bias Noticer developers do not operate a proxy that receives article content.

Data the extension stores on your device

  • Settings (theme, sensitivity, categories, model id)
  • Optional API key (chrome.storage.local only — not synced by the extension)
  • Optional analysis cache and local feedback notes
  • Outlet / journalist scoreboards and compact scan summaries — not full article bodies
  • Technique Academy progress (on-device)

Data sent over the network

  • Only if you provide an xAI API key and run analysis: prompts and article text (or selection/paste) to https://api.x.ai/ using your key.
  • No analytics SDKs ship with the extension.
  • This website (jonbailey.xyz) is separate and may use standard hosting logs.
  • Grades-card PNG/JPEG export is Canvas 2D in the extension. It does not upload article text.

Permissions

storage, activeTab, scripting, sidePanel, contextMenus, host access for https://api.x.ai/* (BYOK only), and host access for http(s) pages so the extension can read the open article and draw non-destructive highlights after you activate it. No extra hosts.

What we do not do

  • No paywall circumvention services
  • No sale of personal information
  • No remote code execution of untrusted scripts
  • No left/right political verdicts

Your controls

Clear local data from Settings. Remove the extension anytime. Manage or revoke your xAI key at the xAI console. Optional “Never send full article text” limited mode.
