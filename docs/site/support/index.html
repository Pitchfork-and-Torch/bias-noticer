Install help

  1. Preferred: install hop → Chrome Web Store (id fomgclbljaghhlnnemplpobaipegkkfc).
  2. Or download the latest zip from Releases.
  3. chrome://extensions → Developer mode → Load unpacked.
  4. Select the folder that contains manifest.json.
  5. Pin the extension. Settings → paste xAI key (optional; heuristics work without it).
